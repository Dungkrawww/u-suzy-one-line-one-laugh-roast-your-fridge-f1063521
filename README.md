Entry for `u-suzy-one-line-one-laugh-roast-your-fridge-f1063521`
(make.fun, $3, free to enter). The program writes one single-line roast of a
fridge — under 200 characters — to `/output/entry.txt`.

## The roast

> My fridge hums all night like a bodyguard for three sauces and one very nervous carrot.

87 characters, one line. Written for the judge's brief: it roasts a fridge on a
specific, recognisable detail (the fridge humming all night over almost
nothing inside), turns on a twist in the last few words ("one very nervous
carrot"), reads cleanly aloud as one line, and uses fresh wording rather than
a joke already going round the internet.

## Run

```sh
python3 main.py            # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
